## Состав поставки

Это накладной патч к 1.3.0, а не полный проект. Скопируйте содержимое папки tzbiz-hotfix-1.3.1 в корень существующего репозитория с заменой соответствующих файлов, затем commit/push. Не заменяйте рабочий .env файлом .env.example. Инструкция развёртывания: HOTFIX-1.3.1.md.

В архиве нет node_modules, .next, базы данных, секретов и пользовательских загрузок. Новых миграций нет. Сгенерированный prisma/schema.prisma не включён: npm run db:generate создаст его для серверной БД.
